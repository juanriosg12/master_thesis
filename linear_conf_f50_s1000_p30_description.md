# Dataset: `linear_conf_f50_s1000_p30`

## 1. Dataset Overview

The name encodes all key parameters:

| Token | Meaning | Value |
|---|---|---|
| `linear` | Functional form between features | Strictly additive linear |
| `conf` | Confounding structure | 5 hidden confounders present |
| `f50` | Number of input features | 50 (X0 … X49) |
| `s1000` | Number of observations | 1,000 |
| `p30` | Y-parents ratio | 0.3 → 15 direct causes of Y |

The full design matrix is 51 columns: 50 feature variables + 1 continuous target Y, with 1,000 rows → 80/20 split → **800 training / 200 test** observations. Random seed is fixed at 42.

This dataset replaces the earlier `p50` variant as the primary benchmark. The two key design changes are:
- **Graph density reduced**: `edge_probability` lowered from 0.2 → 0.07, matching the Sachs real-data density (~1.7 edges/node across 10 nodes).
- **Fewer Y-parents**: `y_parents_ratio` lowered from 0.5 → 0.3, so only 15 out of 50 features directly cause Y (vs. 25 before), creating a clearer causal vs. non-causal attribution contrast.

---

## 2. Feature Relationships (Linear Structure)

Each feature $X_j$ is generated following the causal order of a DAG:

$$X_j = \sum_{i \in \text{Pa}(j)} w_{ij} \cdot X_i + \varepsilon_j, \quad \varepsilon_j \sim \mathcal{N}(0,\, 0.5)$$

- Structural coefficients $w_{ij} \sim \text{Uniform}(0.5,\, 2.0) \times \{-1, +1\}$ — randomly signed, bounded away from zero to avoid weak effects.
- After accumulating parent contributions, each variable is **normalized** (outliers clipped at ±5σ, then standardized) to prevent signal explosion along deep paths.
- The target Y is generated the same way from its 15 parents: $Y = \sum_{k \in \text{Pa}(Y)} \beta_k \cdot X_k + \varepsilon_Y$.

---

## 3. Graph Structure and Connectivity

The DAG over the 50 features is generated by a **two-step procedure** that
produces a uniformly random causal ordering of variables:

1. **Upper-triangular skeleton**: edges are sampled on the $\binom{50}{2} = 1{,}225$ candidate pairs with Erdős–Rényi probability $p = 0.07$. Acyclicity is guaranteed by construction.
2. **Random permutation**: a uniformly random permutation $P$ is applied to both rows and columns of the skeleton — $A' = P A P^\top$. The resulting adjacency represents the same DAG under a randomly shuffled variable labelling, so causal parents are no longer necessarily lower-indexed than their children. The topological order is stored as $\operatorname{argsort}(P)$ for use during data generation.

This design ensures causal discovery algorithms cannot exploit a trivial
index-ordering bias; edges appear in both upper and lower triangles of the
adjacency matrix.

| Quantity | Value |
|---|---|
| Actual X→X edges | **87** |
| Connectivity rate (X→X only) | $87 / 1{,}225 \approx$ **7.1%** |
| Average in-degree per feature | $87 / 50 \approx$ **1.74 parents/node** |
| Direct causes of Y (X→Y) | **15** (y_parents_ratio = 0.3) |
| Total edges in true full DAG | **137** (87 X→X + 50 X→Y\*) |

\* The true full adjacency used for causal discovery evaluation records **50 X→Y edges** because the pipeline sets `feature_selection=False` in the LGBM model, so all 50 features are treated as potential Y predictors in the evaluation reference graph. With confounders present, indirect statistical paths from non-parent features to Y are also captured.

**Comparison with Sachs real data:**

| Dataset | Nodes | X→X edges | Edges/node | Density |
|---|---|---|---|---|
| Sachs (real) | 10 | 16 | 1.60 | 35.6% |
| `linear_conf_f50_s1000_p30` | 50 | 87 | 1.74 | 7.1% |
| `linear_conf_f50_s1000_p50` (old) | 50 | 266 | 5.32 | 21.7% |

## 4. What Confounders Mean in This Dataset

The dataset contains **5 hidden (latent) confounders**. Each confounder $H_c$ is a standard normal variable not included in the feature matrix, but it **additively influences 2–3 observed features simultaneously**:

$$X_i \mathrel{+}= \alpha_{ci} \cdot H_c, \quad \alpha_{ci} \sim \text{Uniform}(0.5,\, 1.5) \times \{-1, +1\}$$

**In practice this means:**
- Two observed features that share a hidden common cause will appear correlated in the data, even if there is no direct causal edge between them.
- Both **LiNGAM** and **PC** assume *causal sufficiency* (no hidden common causes). When this assumption is violated, both algorithms are expected to hallucinate spurious directed edges between the affected feature pairs.
- With the sparser graph (87 X→X edges vs. 266 in p50), the impact of confounders is proportionally more visible: the 5 latent variables affect a higher fraction of the graph's edges.

## 5. Predictive Model: LightGBM Regressor

The model is a **LightGBMRegressor** with full **Optuna-based hyperparameter optimization** (50 TPE trials), using RMSE as the objective. The search space is:

| Hyperparameter | Range |
|---|---|
| `n_estimators` | [50, 500] |
| `learning_rate` | [0.01, 0.30] (log scale) |
| `num_leaves` | [20, 150] |
| `max_depth` | [3, 12] |
| `min_child_samples` | [5, 100] |
| `subsample` | [0.60, 1.0] |
| `colsample_bytree` | [0.60, 1.0] |
| `reg_alpha`, `reg_lambda` | [1e-8, 10.0] (log scale) |

Training uses an internal 80/20 validation split with **early stopping** (20 rounds). All 50 features were used (no feature selection was applied for this dataset).

**Test-set performance:**

| Metric | Value |
|---|---|
| R² | **0.9000** |
| MSE | 2.9437 |
| MAE | 1.3566 |
| RMSE | 1.7157 |

The high R² (0.90) reflects the linear structure. Compared to the `p50/conf` variant (R² = 0.91), performance is nearly identical — the sparser graph produces less cumulative signal amplification along deep causal chains, but the 5 hidden confounders still inject extra exploitable variance through indirect paths.

## 6. Causal Discovery Performance

Both algorithms were run on the **800-sample training set** with significance level $\alpha = 0.05$.

### 6.1 Full Graph (X→X + X→Y edges)

The evaluation reference graph (`true_full_adj`) has **137 edges**: 87 X→X edges plus 50 X→Y edges. The discovered adjacency also includes 50 X→Y edges added by the pipeline heuristic (same LGBM-selected features), so all X→Y edges count as true positives.

| Algorithm | TP | FP | FN | Precision | Recall | F1 | SHD | Edges found |
|---|---|---|---|---|---|---|---|---|
| **PC** | 90 | 14 | 47 | **0.865** | 0.657 | 0.747 | 61 | 104 |
| **LiNGAM** | 74 | 81 | 63 | 0.477 | **0.540** | 0.507 | 144 | 155 |

### 6.2 X→X Edges Only (actual causal structure recovered)

PC and LiNGAM only discover **X→X edges** — the X→Y edges are appended by the same pipeline heuristic to both the discovered and reference graph, so they cancel out in X→X-only evaluation. This section reflects the true structural recovery quality.

The X→X block has **87 true edges** ($\binom{50}{2}\times 0.07 \approx 87$).

| Algorithm | TP | FP | FN | Precision | Recall | F1 | SHD | Edges found |
|---|---|---|---|---|---|---|---|---|
| **PC** | 40 | 14 | 47 | **0.741** | 0.460 | **0.567** | 61 | 54 |
| **LiNGAM** | 24 | 81 | 63 | 0.229 | 0.276 | 0.250 | 144 | 105 |

**Reading the results:**

- **PC** dramatically outperforms the p50 counterpart (F1 = 0.567 vs. 0.229). With a sparser graph, the conditional independence tests have fewer competing paths to separate, and the Fisher-z test at 800 samples is far more reliable. Precision is 0.741 — when PC reports an X→X edge it is correct nearly 3 out of 4 times.

- **LiNGAM** also improves over p50 (F1 = 0.250 vs. 0.177), but the 5 hidden confounders still cause significant over-discovery: 105 edges found vs. 87 true, with only 24 correct. The violation of causal sufficiency means LiNGAM cannot distinguish direct causal paths from confounder-induced correlations.

- The gap **PC >> LiNGAM** (F1: 0.567 vs. 0.250) is wide enough to create a meaningful structural difference in the graphs fed to causal Shapley methods, which is the core comparison the thesis exploits.

---

## Summary

`linear_conf_f50_s1000_p30` is the **sparse-graph, confounded benchmark**: 1,000 samples over 50 linearly-related features with a sparse, randomly ordered DAG (~7% connectivity, 1.74 edges/node) matching the Sachs real-data density profile. The linear structure makes it highly learnable for LGBM (R² = 0.90). The 5 hidden confounders represent the core challenge: they violate causal sufficiency and degrade LiNGAM more than PC. In the X→X-only evaluation, PC achieves F1 = 0.567 (high precision, moderate recall) while LiNGAM achieves F1 = 0.250. With only 15 direct Y-parents out of 50 features (30%), there is a clear causal vs. non-causal split that the graph-informed Shapley methods can exploit. These imperfect discovered graphs are then used as structural priors for the Shapley comparison, and the quality gap between the two algorithms is precisely what the thesis aims to measure.
