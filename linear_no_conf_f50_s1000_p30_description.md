# Dataset: `linear_no_conf_f50_s1000_p30`

## 1. Dataset Overview

The name encodes all key parameters:

| Token | Meaning | Value |
|---|---|---|
| `linear` | Functional form between features | Strictly additive linear |
| `no_conf` | Confounding structure | No hidden confounders |
| `f50` | Number of input features | 50 (X0 … X49) |
| `s1000` | Number of observations | 1,000 |
| `p30` | Y-parents ratio | 0.3 → 15 direct causes of Y |

The full design matrix is 51 columns: 50 feature variables + 1 continuous target Y, with 1,000 rows → 80/20 split → **800 training / 200 test** observations. Random seed is fixed at 42.

This dataset replaces the earlier `p50` variant as the primary benchmark. The two key design changes are:
- **Graph density reduced**: `edge_probability` lowered from 0.2 → 0.07, matching the Sachs real-data density (~1.7 edges/node across 10 nodes).
- **Fewer Y-parents**: `y_parents_ratio` lowered from 0.5 → 0.3, so only 15 out of 50 features directly cause Y (vs. 25 before), creating a clearer causal vs. non-causal attribution contrast.

---

## 2. Feature Relationships (Linear Structure)

Each feature $X_j$ is generated following the causal order of a DAG:

$$X_j = \sum_{i \in \text{Pa}(j)} w_{ij} \cdot X_i + \varepsilon_j, \quad \varepsilon_j \sim \mathcal{N}(0,\, 0.5)$$

- Structural coefficients $w_{ij} \sim \text{Uniform}(0.5,\, 2.0) \times \{-1, +1\}$ — randomly signed, bounded away from zero to avoid weak effects.
- After accumulating parent contributions, each variable is **normalized** (outliers clipped at ±5σ, then standardized) to prevent signal explosion along deep paths.
- The target Y is generated the same way from its 15 parents: $Y = \sum_{k \in \text{Pa}(Y)} \beta_k \cdot X_k + \varepsilon_Y$.
- No hidden confounders are added — the observed feature set is **causally sufficient**.

---

## 3. Graph Structure and Connectivity

The DAG over the 50 features is generated by a **two-step procedure** that
produces a uniformly random causal ordering of variables:

1. **Upper-triangular skeleton**: edges are sampled on the $\binom{50}{2} = 1{,}225$ candidate pairs with Erdős–Rényi probability $p = 0.07$. Acyclicity is guaranteed by construction.
2. **Random permutation**: a uniformly random permutation $P$ is applied to both rows and columns of the skeleton — $A' = P A P^\top$. The resulting adjacency represents the same DAG under a randomly shuffled variable labelling, so causal parents are no longer necessarily lower-indexed than their children. The topological order is stored as $\operatorname{argsort}(P)$ for use during data generation.

This design ensures causal discovery algorithms cannot exploit a trivial
index-ordering bias; edges appear in both upper and lower triangles of the
adjacency matrix.

| Quantity | Value |
|---|---|
| Actual X→X edges | **87** |
| Connectivity rate (X→X only) | $87 / 1{,}225 \approx$ **7.1%** |
| Average in-degree per feature | $87 / 50 \approx$ **1.74 parents/node** |
| Direct causes of Y (X→Y) | **15** (y_parents_ratio = 0.3) |
| Total edges in true full DAG | **137** (87 X→X + 50 X→Y\*) |

\* The true full adjacency records **50 X→Y edges** because the pipeline sets `feature_selection=False` in the LGBM model, so all 50 features are treated as potential Y predictors in the evaluation reference graph — reflecting the full set of features available to the model during prediction.

**Comparison with Sachs real data:**

| Dataset | Nodes | X→X edges | Edges/node | Density |
|---|---|---|---|---|
| Sachs (real) | 10 | 16 | 1.60 | 35.6% |
| `linear_no_conf_f50_s1000_p30` | 50 | 87 | 1.74 | 7.1% |
| `linear_no_conf_f50_s1000_p50` (old) | 50 | 266 | 5.32 | 21.7% |

## 4. No Hidden Confounders

This dataset satisfies **causal sufficiency** — all common causes of any pair of observed features are themselves observed. This is the standard assumption for both LiNGAM and PC:

- No spurious correlations are injected beyond what the DAG structure already creates through shared ancestors.
- Both algorithms should perform better here than on the `conf` variant, since their key assumption is not violated.
- LiNGAM can exploit the linear non-Gaussian signal without confounder interference; PC's conditional independence tests face only the true DAG structure.
- The random DAG permutation still makes the task non-trivial — causal parents are not trivially identified by index ordering.

---

## 5. Predictive Model: LightGBM Regressor

The model is a **LightGBMRegressor** with full **Optuna-based hyperparameter optimization** (50 TPE trials), using RMSE as the objective. The search space is:

| Hyperparameter | Range |
|---|---|
| `n_estimators` | [50, 500] |
| `learning_rate` | [0.01, 0.30] (log scale) |
| `num_leaves` | [20, 150] |
| `max_depth` | [3, 12] |
| `min_child_samples` | [5, 100] |
| `subsample` | [0.60, 1.0] |
| `colsample_bytree` | [0.60, 1.0] |
| `reg_alpha`, `reg_lambda` | [1e-8, 10.0] (log scale) |

Training uses an internal 80/20 validation split with **early stopping** (20 rounds). All 50 features were used (no feature selection was applied for this dataset).

**Test-set performance:**

| Metric | Value |
|---|---|
| R² | **0.8939** |
| MSE | 3.7797 |
| MAE | 1.5345 |
| RMSE | 1.9442 |

The slightly lower R² (0.89) compared to the `conf` variant (0.90) is consistent with expectations: without confounders, the model cannot exploit extra variance introduced by latent common causes — only direct and mediated effects through the observed DAG contribute to predictable signal. Compared to `no_conf/p50` (R² = 0.84), the higher R² here reflects the sparser graph producing less noise from distant indirect paths.

## 6. Causal Discovery Performance

Both algorithms were run on the **800-sample training set** with significance level $\alpha = 0.05$.

### 6.1 Full Graph (X→X + X→Y edges)

The evaluation reference graph (`true_full_adj`) has **137 edges**: 87 X→X edges plus 50 X→Y edges. The discovered adjacency also includes 50 X→Y edges added by the pipeline heuristic (same LGBM-selected features), so all X→Y edges count as true positives.

| Algorithm | TP | FP | FN | Precision | Recall | F1 | SHD | Edges found |
|---|---|---|---|---|---|---|---|---|
| **PC** | 87 | 8 | 50 | **0.916** | 0.635 | **0.750** | 58 | 95 |
| **LiNGAM** | 72 | 59 | 65 | 0.550 | **0.526** | 0.537 | 124 | 131 |

### 6.2 X→X Edges Only (actual causal structure recovered)

PC and LiNGAM only discover **X→X edges** — the X→Y edges are appended by the same pipeline heuristic to both the discovered and reference graph, so they cancel out in X→X-only evaluation. This section reflects the true structural recovery quality.

The X→X block has **87 true edges** ($\binom{50}{2}\times 0.07 \approx 87$).

| Algorithm | TP | FP | FN | Precision | Recall | F1 | SHD | Edges found |
|---|---|---|---|---|---|---|---|---|
| **PC** | 37 | 8 | 50 | **0.822** | 0.425 | **0.561** | 58 | 45 |
| **LiNGAM** | 22 | 59 | 65 | 0.272 | 0.253 | 0.262 | 124 | 81 |

**Reading the results:**

- **PC** achieves its best performance on this dataset: precision 0.822 means that 4 out of 5 reported X→X edges are correct. With no confounders and a sparse graph, the conditional independence tests have clear separation between edges and non-edges at 800 samples. Recall (0.425) is limited by the conservative $\alpha = 0.05$ threshold — PC misses about half the true edges but has very few false positives (only 8).

- **LiNGAM** performs worse than PC (F1 = 0.262 vs. 0.561). Without confounders, LiNGAM's assumption is satisfied, yet it still over-discovers: 81 edges found vs. 87 true, but only 22 are correct (precision = 0.272). The random permutation of variable labels prevents LiNGAM from trivially recovering the upper-triangular causal ordering, and the algorithm produces many spurious directed edges.

- Compared to the `conf` variant, **PC improves slightly** (F1 = 0.561 vs. 0.567 — nearly identical) while **LiNGAM improves** (F1 = 0.262 vs. 0.250). The `no_conf` setting is the more favorable one for both algorithms as expected, though the gap is modest here due to the permuted ordering.

- The clear structural gap **PC >> LiNGAM** (F1: 0.561 vs. 0.262) makes this the primary dataset for thesis comparisons: Shapley methods using PC's sparser, higher-quality graph should show meaningfully different attributions from those using LiNGAM's noisier graph.

---

## Summary

`linear_no_conf_f50_s1000_p30` is the **causally clean, sparse-graph benchmark**: 1,000 samples over 50 linearly-related features with no hidden confounders and a sparse DAG (~7% connectivity, 1.74 edges/node) matching the Sachs real-data density profile. It is the primary thesis dataset — both discovery algorithms operate under their intended assumptions, and the sparser graph produces the best causal discovery F1 scores in the experimental suite. The LGBM model achieves R² = 0.89. In the X→X-only evaluation, PC reaches F1 = 0.561 (precision 0.822, 45 edges found) and LiNGAM reaches F1 = 0.262 (81 edges found). With only 15 direct Y-parents out of 50 features (30%), the causal/non-causal attribution contrast is sharp. Comparing this dataset to `linear_conf_f50_s1000_p30` isolates the pure effect of causal sufficiency violation on both discovery quality and downstream Shapley attribution.
